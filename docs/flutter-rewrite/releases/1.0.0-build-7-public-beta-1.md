>
> 版本：`1.0.0+7`
>
> 版本节点：`Public Beta 1`
>
> 节点日期：2026-07-25
>
> 验证状态：代码与文档已静态整理，等待用户完成构建、双端真机和真实书源验收。

## 1. 发布目标

本节点用于冻结首个公开内测版本的源码范围，让外部测试者开始验证 Android 与 iOS 上的核心阅读闭环、账号与服务端能力、书源兼容性、数据隔离和跨版本升级行为。

公开内测不代表所有迁移阶段已经通过。当前仍以收集真实设备、真实书源和异常路径反馈为主要目标，不能将本节点标记为稳定版或完整功能版。

## 2. 当前内测范围

本版本提供以下主要入口和已写入能力：

- App 注册、登录、安全会话恢复、退出登录和全局认证门；
- 书源导入、编辑、启停、分组、二维码入口和服务端书源同步；
- 普通规则与当前已接入的 JavaScript 书源执行链；
- 多书源搜索、搜索历史、书源筛选、结果匹配和书源成功率参与排序；
- 书籍详情、目录、加入书架、书架分组、阅读历史和按登录用户隔离的本地数据；
- 文本阅读、章节切换、进度恢复、分页/滚动、书签、替换、标注、显示设置和单章/整书换源；
- 本地书导入、PDF 阅读入口和离线下载管理；
- Android/iOS 准入检查、升级提示、崩溃报告、匿名埋点和日志管理。

以上能力表示源码已进入内测范围，不等同于所有平台、书源和异常路径已经验收通过。

## 3. 本版本节点最后纳入的改动

### 3.1 安装包版本身份与升级状态

- Android 从 `PackageManager` 读取实际安装包 `versionName`；
- iOS 从 `CFBundleShortVersionString` 读取实际安装包语义版本；
- 启动时使用实际 `versionName` 判断本地准入与升级缓存是否属于当前安装包；
- 新语义版本不会继续恢复旧版本的强制升级或准入阻断状态；
- 平台版本元数据不可用时不恢复旧准入缓存，等待网络重新确认；
- Android versionCode 与 iOS build number 继续上报，但不参与跨平台语义版本缓存身份判断。

### 3.2 升级地址展示与打开

- 服务端返回的非空下载地址始终完整展示并支持长按复制；
- 合法 HTTP/HTTPS 地址可以交给系统外部浏览器打开；
- 无法自动打开的地址仍保持可见和可复制；
- 更新说明区域支持滚动，避免长文本导致弹窗溢出；
- iOS 只提供外部跳转，不在 App 内自动下载或安装。

### 3.3 云端书源同步后的搜索刷新

- 搜索页持续观察启用且可见的书源；
- 云端同步、手动导入、编辑、启停或删除书源后，保活搜索页无需重启 App 即可更新候选；
- 已开始的搜索继续使用启动时快照，避免运行中的 worker 数量和结果突然变化；
- 下一次搜索自动使用最新书源；
- 搜索 ViewModel 销毁时取消订阅，避免生命周期结束后更新和内存泄漏。

## 4. 数据与覆盖安装基线

| 项目 | 当前值 |
|---|---|
| Android applicationId | `io.legado.flutter` |
| iOS Bundle Identifier | `io.legado.flutter` |
| versionName | `1.0.0` |
| Android versionCode / iOS build number | `7` |
| SQLite 文件 | `legado_flutter.db` |
| SQLite Schema | `9` |

从旧构建覆盖安装时必须保持 applicationId、Bundle Identifier 和签名身份一致。Schema v9 包含按登录用户隔离的书架、分组、目录、阅读历史、进度和下载附属状态；旧 Schema 升级行为需要在真实存量数据上验证。

当前 Android `release` 构建仍复用 debug 签名配置。公开内测包必须固定实际使用的签名证书；后续切换证书通常无法直接覆盖已安装版本。

## 5. 已知限制与未完成门禁

- 本节点未获得完整的 Android 与 iOS 构建、安装、启动和真机回归结果；
- M4 JavaScript 兼容仍受真实书源样本、WebView/Cookie、资源嗅探和 Java Helper 长尾影响；
- Android A2 核心闭环与 iOS 第一批真机门禁尚未全部由用户确认通过；
- 本地书可选择的格式多于当前真实解析器，不能把文件选择器中出现的扩展名都视为已支持；
- MOBI、AZW、AZW3 和压缩容器仍不能宣称完整可用；
- TTS、AI、同步、漫画、音频、RSS、Web 服务和部分高级能力仍属于后续迁移或待验收范围；
- 当前仓库没有自动构建、测试、分析或格式化结果可作为本节点的发布证据。

## 6. 外部测试重点

1. Android 与 iOS 首次安装、登录、退出、重启和会话恢复。
2. 真实书源导入、云端同步、启停、编辑和删除后搜索页的实时刷新。
3. 搜索、详情、目录、加入书架、阅读、章节切换、退出重进和进度恢复。
4. JavaScript 书源的搜索、详情、目录、正文、登录、验证码、Cookie 和 WebView 行为。
5. 多账号切换后的书架、历史、目录、进度和下载数据隔离。
6. 从旧构建覆盖安装后的数据库升级、旧数据处理和本地书读取。
7. 普通更新、强制更新、准入拒绝、离线启动和语义版本变化后的缓存失效。
8. 长时间搜索、阅读、下载和反复切页后的性能、动画流畅度、资源释放与内存占用。
