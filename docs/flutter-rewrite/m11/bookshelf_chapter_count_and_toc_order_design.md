# 书架章节总数与目录正倒序切换设计

状态：`IMPLEMENTED_PENDING_USER_VERIFICATION`

日期：2026-07-27

## 1. 目标

本次调整包含两个互相独立、但都依赖章节索引正确性的 UI 行为：

1. 书架中的书籍没有未读章节时，不再完全隐藏章节信息；目录总数有效时显示该书共有多少章。
2. 书籍详情页的完整目录、阅读界面的目录增加正序/倒序切换，目录每次打开时默认正序。

本方案只改变展示和目录的可见顺序，不修改章节数据、阅读进度、数据库结构或远端目录顺序。

## 2. 当前实现

### 2.1 书架章节角标

- `BookshelfViewModel` 根据 `totalChapterNum - durChapterIndex - 1` 计算未读章节数，并把负数收敛为 `0`。
- 书架列表模式仅在 `unreadChapterCount > 0` 时显示数字 Badge。
- 书架网格模式仅在 `unreadChapterCount > 0` 时显示“`N 章未读`”覆盖层。
- 因此一本书全部读完时，列表和网格都不显示任何章节数量。

### 2.2 书籍详情目录

- `book_info_screen.dart` 中的完整目录底部弹层直接以 `state.chapters[index]` 构建行。
- 点击目录行时直接把当前列表索引作为章节索引返回。
- 当前弹层没有自己的排序状态。

### 2.3 阅读界面目录

- `reader_route.dart` 中的 `_ReaderTocSheetBody` 已经是有状态组件。
- `_visibleChapterIndexes` 负责按“是否显示卷标题”生成可见的原始章节索引列表。
- 高亮、点击跳章和初始滚动位置都依赖该原始章节索引列表。
- 当前目录固定为正序。

## 3. 书架章节数量展示规则

列表和网格共用以下业务规则：

| 条件 | 展示 |
| --- | --- |
| `unreadChapterCount > 0` | 保持现有未读提示 |
| `unreadChapterCount == 0` 且 `totalChapterNum > 0` | 显示“共 N 章” |
| `totalChapterNum <= 0` | 不显示章节角标，避免展示“共 0 章” |

具体 UI：

- 列表模式：保留现有未读数字 Badge；全部读完时显示内容为“共 N 章”的紧凑 Badge。
- 网格模式：保留现有“`N 章未读`”覆盖层；全部读完时在同一位置显示“`共 N 章`”。
- 不新增独立状态，不复制保存章节总数，直接使用 `Book.totalChapterNum`，避免状态不一致。

## 4. 目录排序的索引原则

正倒序只改变“可见位置到原始章节索引”的映射，不能反转或改写 `state.chapters`。

例如原目录为 `[0, 1, 2, 3]`：

- 正序可见索引：`[0, 1, 2, 3]`
- 倒序可见索引：`[3, 2, 1, 0]`

无论显示顺序如何：

- 当前章节高亮仍比较原始章节索引。
- 点击目录行仍传递原始章节索引。
- 阅读进度和章节缓存仍使用原始章节索引。
- 章节序号仍显示书籍目录中的真实序号，不使用倒序后的行号。

目录排序状态为弹层内的临时 UI 状态：

- 每次打开默认正序。
- 关闭弹层后不持久化。
- 不增加 Contract、ViewModel、Repository 或数据库字段。

## 5. 书籍详情页完整目录

调整 `lib/src/ui/book_info/book_info_screen.dart`：

1. 为完整目录弹层增加局部状态 `descending`，初始值为 `false`。
2. 在目录标题区域增加正序/倒序切换按钮，同时提供图标、文字或 Tooltip，不能只靠难以辨认的图标表达状态。
3. 使用 O(1) 映射计算真实章节索引：

   ```text
   chapterIndex = descending
       ? chapterCount - 1 - visibleIndex
       : visibleIndex
   ```

4. 行内容读取 `state.chapters[chapterIndex]`。
5. 点击时返回 `chapterIndex`，不能返回 `visibleIndex`。

详情页顶部的少量章节预览不承担完整目录排序功能，保持现有展示；用户点击“查看全部目录”后在完整目录弹层内切换。

## 6. 阅读界面目录

调整 `lib/src/ui/reader/reader_route.dart`：

1. 在 `_ReaderTocSheetBodyState` 增加 `descending`，初始值为 `false`。
2. 在目录标题区增加正序/倒序切换控件，并与现有“卷标题”筛选控件保持窄屏可用，避免固定宽度 Row 在大字体下溢出。
3. `_visibleChapterIndexes` 按当前方向直接遍历一次章节数组：
   - 正序从 `0` 到 `length - 1`；
   - 倒序从 `length - 1` 到 `0`；
   - 遍历期间继续应用现有卷标题过滤规则。
4. 倒序时按完整目录行严格反转，卷标题也跟随原始目录行反转。
5. 高亮和 `OpenReaderChapterIntent` 继续使用可见列表中保存的原始章节索引。
6. 切换顺序后，在下一帧把当前章节重新定位到可见区域；使用 `jumpTo`，避免长目录从一端执行耗时较长的滚动动画。
7. “显示/隐藏卷标题”切换也复用当前章节定位逻辑，避免筛选后目录停留在无关位置。

## 7. 性能和内存约束

- 不复制、反转或修改完整章节实体列表。
- 详情目录通过算术映射完成倒序，不创建额外索引数组。
- 阅读目录本来就需要一个过滤后的索引列表；按方向一次遍历生成，避免先生成正序列表再 `reversed.toList()` 造成第二次 O(n) 分配。
- 排序状态只随目录弹层存活，弹层释放后不保留监听器或额外引用。
- 复用现有 `ScrollController`，不在每次重建时创建控制器。
- 切换时只重建目录弹层，不触发书籍详情页、阅读正文或书架整体刷新。

## 9. 验收要点

### 9.1 书架

- 有未读章节：列表和网格继续显示原有未读提示。
- 全部章节已读且总章数大于 0：列表和网格显示“共 N 章”。
- 目录未知或总章数为 0：不显示“共 0 章”。
- 列表/网格切换后规则一致。

### 9.2 书籍详情目录

- 每次打开完整目录默认正序。
- 切换倒序后首行是最后一章，再次切换恢复正序。
- 正序和倒序点击同一章都打开正确章节。
- 关闭后重新打开恢复默认正序。

### 9.3 阅读界面目录

- 每次打开目录默认正序。
- 正倒序切换后当前章节仍被正确高亮并重新进入可见区域。
- 倒序点击章节打开正确正文，阅读进度不串章。
- 显示和隐藏卷标题在两种顺序下都正常。
- 超长目录切换时不执行跨越大量章节的滚动动画，不额外复制章节实体。
