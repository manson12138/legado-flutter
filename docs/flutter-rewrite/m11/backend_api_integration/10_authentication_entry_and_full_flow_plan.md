## 1. 目标与范围

目标：未登录用户不能进入书架、搜索、书源、阅读或设置等业务页面；应用启动先恢复持久会话，恢复成功进入主界面，恢复失败或不存在会话时显示完整登录注册界面。

本次包含：

- 应用级认证门，覆盖正常路由内容但不替代服务端的强制升级/准入门；
- 登录、注册、邀请码、密码可见性切换、提交中状态、字段校验、错误反馈与登录后自动进入业务页；
- 复用现有 RSA-OAEP-SHA256 密码加密、密码公钥刷新、Access/Refresh Token 安全持久化、会话恢复和权限读取链路；
- 在“我的/设置”保留账号信息与退出登录入口；退出后立即返回认证门；
- 登录、注册和会话恢复过程的无障碍标签、键盘焦点、滚动避让与资源释放。

不包含：忘记密码、第三方登录、短信/邮箱验证码、账号资料编辑、服务端 API 与数据库结构修改、将 token/密码写入普通缓存或日志。

## 2. 现状与问题

| 区域 | 当前行为 | 问题 | 改造 |
| --- | --- | --- | --- |
| `AuthenticationRoute` | 从设置页进入，展示账号操作 | 未登录仍可停留在主界面 | 改为由应用级认证门承载，同时保留设置内账号入口供已登录用户查看和退出 |
| `LegadoApp` | 启动和前台恢复调用 `restoreSession()` | 没有根据会话状态阻止子页面 | 在 AppAccess 覆盖层内增加认证门，等待恢复时显示启动状态，未登录时全屏认证 UI |
| `AuthenticationGateway` | 已提供会话监听、登录/注册、权限读取及安全会话恢复 | UI 状态与启动门未统一 | 认证门和认证页共同订阅同一会话状态，不复制 token 或网络逻辑 |
| API/数据层 | 已有 RSA 密码加密及双 Token 持久化设计 | 不得被 UI 重写或旁路 | 继续由 Repository/API 处理公钥、重试、刷新与安全存储 |

## 3. 状态与流程

```text
应用启动 / 回到前台
  -> AuthenticationGateway.restoreSession()
  -> 恢复中：认证门显示不可交互启动页
  -> 有效会话：移除认证门，展示已有业务页面
  -> 无会话、刷新失败或会话失效：认证门显示登录页

登录
  -> UI 本地校验用户名与密码非空
  -> ViewModel 调用 AuthenticationGateway.login()
  -> API 获取或刷新 RSA 公钥、加密密码、提交登录
  -> 安全写入会话并获取权限
  -> 会话通知认证门自动关闭，进入业务页

注册
  -> 输入用户名、密码、确认密码、邀请码
  -> 本地校验密码一致和邀请码非空
  -> ViewModel 调用 AuthenticationGateway.register()
  -> 成功后切回登录页并预填用户名（不保留密码）
  -> 用户主动登录后进入业务页

退出登录
  -> 清除安全会话和内存会话
  -> 认证门立即覆盖当前业务页，显示登录页
```

会话恢复必须有明确的 `restoring / authenticated / unauthenticated` UI 状态；不能以 `session == null` 直接判定未登录，否则启动时会闪现登录页。恢复失败时将敏感错误归类为“登录已失效，请重新登录”，不显示 token、服务端响应体或加密细节。

## 5. UI 与交互要求

- 默认显示登录页；注册通过文本按钮切换，切换时清空密码与确认密码，不清空用户名或邀请码输入。
- 输入框使用 `autofillHints`、正确的 `TextInputAction` 和 `FocusNode` 串联；键盘弹出时通过可滚动安全区域避免遮挡提交按钮。
- 提交时禁用重复点击、切换页签和退出按钮；不使用整页无意义动画，页面切换使用短时 `AnimatedSwitcher` 保持稳定布局。
- 字段错误显示在对应输入项下；服务端/网络错误显示为通用消息，不显示原始 `message`、响应体、用户名、密码、密文、公钥、Cookie 或 token。
- 注册成功不自动登录，避免后端注册响应与登录会话语义混淆；用户显式登录后才进入应用。
- 认证门使用 `PopScope(canPop: false)`；系统返回键不能绕过登录要求。

## 6. 安全与性能

- 密码只存在输入控制器和单次提交局部变量中；成功、失败、切页、页面销毁后立即清空；不得写日志。
- 不在 Widget、ViewModel 或缓存中持有公钥、token、Authorization、Cookie 或加密请求体；继续使用既有安全会话存储边界。
- 公钥过期仅允许由 Repository 按既有契约进行受控单次重试，UI 不自行重放注册/登录请求。
- 认证门和设置页只订阅一个会话监听；路由/控制器/焦点对象在 `dispose` 释放，避免会话切换后重复监听和内存泄漏。

## 7. 用户验收

1. 首次安装或退出登录后，业务页不可见，只能看到登录注册界面。
2. 登录成功后自动进入业务页；关闭再打开 App 后，有效会话恢复时不闪现登录页。
3. Refresh Token 失效、网络恢复失败或安全存储读取失败时，进入登录页并显示安全通用提示。
4. 注册字段校验、密码不一致、邀请码缺失、后端拒绝、网络失败和提交中重复点击均有正确反馈。
5. 注册成功后密码被清空，用户需显式登录；登录/注册日志中不包含敏感字段。
6. 强制升级或服务端准入拒绝时，认证门不能覆盖更高优先级的阻断页面。
