## 当前 Feature

### 1. 整书换源（已实现，等待验收）

- 从书籍详情、书架单选和文本阅读器进入。
- 在当前启用书源中有界并发搜索同名候选，可选作者校验和书源范围。
- 候选必须完成详情和完整目录加载后才允许确认。
- 原子替换旧书主键、旧目录、新书和新目录，并在事务内复查目标主键冲突。
- 可选择迁移阅读进度、分组排序、自定义封面、分类标签、备注简介和单书阅读/显示配置。
- 阅读器入口换源前保存稳定进度，成功后使用新主键替换当前阅读路由。

### 2. 单章换源（已实现，等待验收）

只替换阅读器当前章节的正文，不改变书籍主键；复用整书换源的多源搜索基础设施，新增候选目录
模糊匹配定位目标章节。详见 [专项记录](./chapter_change_source/README.md)。

### 3. 离线下载与下载管理（已实现，等待验收）

阅读器范围下载、独立跨书下载管理页、数据库持久化、全局可配置并发（默认 5、上限 8）、硬超时、五次失败跳章、
暂停恢复、真实离线正文删除和 `98% → 70%` 六级梯度自动下载换源均已接入；自动换源累计最多检查 78 个来源、每级最多深度验证 3 个候选并受 3 分钟全局时限保护，最终不达 70% 时提示手动换源。Android 使用 `dataSync` 前台服务与通知；iOS 使用系统有限
后台执行窗口，窗口结束后保留队列并在下次运行时续传。详见 [专项记录](./offline_download/README.md)。

### 4. 书架历史双页与 API 质量上报（已实现，等待验收）

书架内部已改为书架/历史双页；成功阅读写入独立历史快照但不自动加入书架，阅读器提供仅图标的显式加入入口，
并完成章节滑杆与底栏重排、选择模式返回和可见性退出。书源质量按 `search/toc/content` 最终结果聚合并接入
`/api/v1/booksource/stats/batch` 两阶段协议；匿名埋点已按授权、UUID 幂等、严格白名单和动态字节分批重建，
本专项接入阅读成功/失败事件。详见
[书架与阅读历史双页设计](./reading_history_and_bookshelf_pageview_design.md)。游客或登录账号启动后的书架与历史网络书目录
现在会按 URL 去重、限两个 worker 在后台自动更新，书籍详情主操作区也提供显式“更新目录”按钮；详见
[启动自动更新目录设计](./bookshelf_history_startup_auto_toc_refresh_design.md)。

### 5. 游客与登录用户书架、历史隔离（已实现，等待验收）

本地数据库已升级到 Schema v9，书架、分组、目录、阅读历史、进度和下载附属状态使用用户复合键；
v8 升级按用户确认清空旧书架外键图。认证会话切换会使旧页面、预加载和下载调度代次失效，
未登录使用只限本机的 `userId=-1` 游客作用域，不会回退到无归属公共用户；游客数据不自动迁移到账号。
当前仅保证游客与同设备账号隔离，不包含跨设备同步。详见
[按登录用户隔离设计](./user_scoped_bookshelf_and_history_design.md)和
[非强制登录游客模式](./optional_authentication_guest_mode_design.md)。

### 6. 游客与登录用户搜索历史隔离（已实现，等待验收）

- 搜索关键字历史已按游客或登录用户派生 `caches` 键隔离，每个作用域独立维护最近最多 20 条；
- 旧设备级公共历史在首次访问时删除，不会归属给任一用户；
- `load`、`record`、`clear` 串行执行，并在异步操作前固定用户键，避免快速切换账号串号；
- 不修改数据库 Schema、构建号或设备级搜索匹配偏好；
- 详见 [按登录用户隔离搜索历史设计](./user_scoped_search_history_design.md)。

### 7. 成人内容屏蔽词与书源可见性扩展（已实现，等待验收）

- 内置最低基线新增 `色色`、`耽美`、`腐`、`18`、`色`、`涩涩`、`脸红`，远程启用词只做并集扩展；
- 屏蔽开启时，书源名称或分组包含任一生效词就不展示，也不参与搜索、整书换源或单章换源；
- 继续保留小说名、作者、简介和分类的既有搜索结果过滤，以及书源备注、成人标签和域名规则；
- 规则变化会刷新保活书源列表和搜索选择，取消旧搜索快照但不删除数据库中的同步书源；
- 详见 [成人内容屏蔽词与书源可见性扩展方案](./adult_content_source_visibility_extension_plan.md)。

## 待执行专项：书架/历史到阅读器封面全屏转场

- 用户要求移除书架/历史入口现有的 250ms 中心移动与 3D 开书动画；
- 新方案从被点击 cell 的真实封面位置开始，总时长不超过 300ms；前约 200ms 保持不透明并放大到
  接近全屏，之后才让末段放大与封面淡出重叠，文章从封面下方逐步显现；
- 列表和网格都改为点击时读取真实封面 RenderBox，不再使用固定偏移估算；
- 返回只做约 200ms 淡出，避免书架排序或进度变化后缩回已经失效的旧 cell 位置；
- 不改阅读加载、缓存、进度、数据库、MMKV 或内部翻页动画；
- 代码已写入，等待用户在书架/历史列表、网格、文本书和 PDF 上真机验收；
- 详见 [书架/历史到阅读器封面全屏转场改造方案](./bookshelf_history_reader_cover_transition_design.md)。

明确不包含（三个 Feature 共同边界）：阅读失败后的自动换源、批量换源、书源置顶/禁用/删除、
旧正文缓存批量删除，以及漫画或图片章节离线下载。离线下载自己的受控自动换源已经实现；iOS 不承诺无限后台下载。
