## 当前 Feature

### 1. 整书换源（已实现，等待验收）

- 从书籍详情、书架单选和文本阅读器进入。
- 在当前启用书源中有界并发搜索同名候选，可选作者校验和书源范围。
- 候选必须完成详情和完整目录加载后才允许确认。
- 原子替换旧书主键、旧目录、新书和新目录，并在事务内复查目标主键冲突。
- 可选择迁移阅读进度、分组排序、自定义封面、分类标签、备注简介和单书阅读/显示配置。
- 阅读器入口换源前保存稳定进度，成功后使用新主键替换当前阅读路由。

### 2. 单章换源（已实现，等待验收）

模糊匹配定位目标章节。详见 [专项记录](./chapter_change_source/README.md)。

### 3. 离线下载与下载管理（已实现，等待验收）

阅读器范围下载、独立跨书下载管理页、数据库持久化、全局可配置并发（默认 5、上限 8）、硬超时、五次失败跳章、
暂停恢复、真实离线正文删除和 `98% → 70%` 六级梯度自动下载换源均已接入；自动换源累计最多检查 78 个来源、每级最多深度验证 3 个候选并受 3 分钟全局时限保护，最终不达 70% 时提示手动换源。Android 使用 `dataSync` 前台服务与通知；iOS 使用系统有限
后台执行窗口，窗口结束后保留队列并在下次运行时续传。详见 [专项记录](./offline_download/README.md)。

### 5. 游客与登录用户书架、历史隔离（已实现，等待验收）

v8 升级按用户确认清空旧书架外键图。认证会话切换会使旧页面、预加载和下载调度代次失效，
未登录使用只限本机的 `userId=-1` 游客作用域，不会回退到无归属公共用户；游客数据不自动迁移到账号。
当前仅保证游客与同设备账号隔离，不包含跨设备同步。详见
[按登录用户隔离设计](./user_scoped_bookshelf_and_history_design.md)和

### 6. 游客与登录用户搜索历史隔离（已实现，等待验收）

## 进行中专项：书源封面搜索与替换（代码已写入，等待验收）

- 书架长按单选和书籍详情共用一个封面选择面板；
- 没有已有候选时，自动搜索当前可见且已启用的书源；
- 所有候选必须封面非空，并严格按“书名和作者精确匹配 → 书名精确匹配 → 书名模糊匹配”选择最高层级；
- 并发搜索后到达的高层级结果会替换先到达的低层级结果，不混合展示；
- 选择候选只字段级更新 `customCoverUrl`，恢复默认封面时清空该字段；
- 搜索不到时可从系统图片选择器选取本地图片，立即复制到应用支持目录后再字段级保存，Android/iOS 共用同一入口；
- 本地图片在数据库中使用不含易变沙盒前缀的稳定标识，旧绝对路径自动兼容；书架和已有历史快照同事务更新，页面切换同步命中内存与图片缓存；
- 书架长按单选按钮、详情操作卡、详情菜单与封面长按均已接入共用面板；
- 不新增数据库字段或 MMKV 键，不提升数据库版本和应用构建号；
- 详见 [书源封面搜索与替换设计](./book_cover_source_search_and_replacement_design.md)。

## 待执行专项：书架/历史到阅读器封面全屏转场

- 用户要求移除书架/历史入口现有的 250ms 中心移动与 3D 开书动画；
- 新方案从被点击 cell 的真实封面位置开始，总时长不超过 300ms；封面从动画首帧开始按先快后慢节奏淡出的同时放大，
  文章从封面下方同步显现，并在 200ms 时完全透明；
- 列表和网格都改为点击时读取真实封面 RenderBox，不再使用固定偏移估算；
- 返回只做约 200ms 淡出，避免书架排序或进度变化后缩回已经失效的旧 cell 位置；
- 不改阅读加载、缓存、进度、数据库、MMKV 或内部翻页动画；
- 代码已写入，等待用户在书架/历史列表、网格、文本书和 PDF 上真机验收；
- 首次开书卡顿已按用户要求临时加入统一 Tag `READER_COVER_TRANSITION` 的导航阶段、FrameTiming、
  同步封面缓存检查和图片首帧日志，全部带 `FLUTTER_REWRITE_DEBUG_LOG` 标识，等待用户回传后分析；
- 详见 [书架/历史到阅读器封面全屏转场改造方案](./bookshelf_history_reader_cover_transition_design.md)。
