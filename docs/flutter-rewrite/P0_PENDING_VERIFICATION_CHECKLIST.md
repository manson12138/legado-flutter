# P0 待验证清单

## 1. 文档用途

本文只记录已经有实现、但仍需要用户通过真实书源或 Android/iOS 真机确认的 P0 项目。
它不把“代码存在”当作通过，也不要求在每次代码修改后重复完整验收；可以等 P0 实现集中完成后，按本文一次性验证。

验证范围分为三组：

1. P0-01：真实书源搜索、详情、目录、正文、登录和 WebView 兼容；
2. P0-02：核心阅读稳定性、分页和进度安全；
3. P0-03：整书换源、单章换源和事务安全。

## 2. 结果状态

每个用例只使用以下状态：

| 状态 | 含义 |
|---|---|
| `NOT_RUN` | 尚未执行 |
| `PASS` | 实际结果符合验收条件 |
| `DIFFERENCE` | 可以使用，但与原生 Android 存在已确认差异 |
| `BLOCKED` | 环境、网站、账号或依赖导致无法继续 |
| `FAIL` | 已执行且 Flutter 行为不符合验收条件 |

发现问题时必须记录“平台、书源、业务阶段、操作步骤、实际结果”。日志或截图不得包含完整 Cookie、Token、账号、验证码、请求正文或受版权保护的完整章节。

### 4.6 P0-01D 登录、验证与单提示队列

默认关闭场景：

- [ ] 设置初始值为关闭。
- [ ] 搜索仍执行 `loginCheckJs` 的非交互逻辑。
- [ ] `startBrowser/startBrowserAwait/getVerificationCode` 不弹窗、不打开页面。
- [ ] 需要交互的书源只结束自身任务，其他并发书源继续返回结果。
- [ ] 换源、后台刷新和离线下载不会突然拉起登录或验证码页面。

用户主动开启场景：

- [ ] 多个书源同时申请交互时，同一时间只出现一个提示。
- [ ] 当前确认框或验证页面真正关闭后，下一条请求才出现。

- [ ] `startBrowser` 打开页面后不等待页面结果，行为与原生非等待接口一致。
- [ ] `startBrowserAwait` 完成后返回可用页面结果，并按参数决定重新请求或返回 HTML。
- [ ] 图片验证码携带统一 Cookie，提交值能回到当前脚本。
- [ ] 登录或验证产生的 Cookie 能被后续普通 HTTP 请求使用。
- [ ] 页面返回、搜索停止、搜索页关闭时不残留悬挂任务或叠加弹窗。
- [ ] 界面和日志不展示完整 URL、Cookie、Token 或验证码。

## 5. P0-02 核心阅读稳定性与进度安全

### 5.1 分页和切章竞争

- [ ] 普通章节可进入连续滚动、上下分页和左右分页。
- [ ] 超长章节首屏可操作，后台续算期间菜单和翻页不明显卡死。
- [ ] 极长单段文本不会导致长时间白屏或崩溃。
- [ ] 连续快速翻页、上一章/下一章和目录跳转后，只显示最后选择的章节。
- [ ] 预加载或旧分页结果不会覆盖当前章节。
- [ ] 覆盖、滑动和无动画模式均没有重复页、漏页或卡页。

### 5.2 重排和稳定锚点

- [ ] 修改字号、行距、段距和边距后恢复到接近原文字，而不是章首。
- [ ] 横竖屏切换和窗口尺寸变化后恢复位置合理。
- [ ] 切换翻页模式后章节和位置不倒退。
- [ ] 正文替换规则改变后，不串用旧分页缓存。
- [ ] Dart 正则替换分组结果与原生 Android 的真实规则结果一致，或差异已登记。

### 5.3 进度保存和恢复

- [ ] 正常返回后重新进入，章节和字符位置正确。
- [ ] 切到后台后重新进入，章节和字符位置正确。
- [ ] 杀进程并重新启动后，章节和字符位置正确。
- [ ] 快速切章后立即退出，不保存前一章的延迟结果。
- [ ] 多本书交替阅读时不串进度。
- [ ] 书架进度不会倒退。

### 5.4 长时间与平台能力

- [ ] 普通规则书籍连续阅读至少 30 分钟。

## 6. P0-03 整书换源与单章换源安全

### 6.1 整书换源

- [ ] 可搜索全部启用书源，并能限制候选范围。
- [ ] 停止任务后不再追加结果，已有候选仍可查看。
- [ ] 候选详情和完整目录加载成功后才能提交换源。
- [ ] 取消换源或候选失败时，原书、目录和进度完全不变。
- [ ] 模拟或遇到提交失败时，事务整体回滚。
- [ ] 换源成功后，书架、详情和阅读器不再持有旧 `bookUrl`。
- [ ] 分组排序、自定义封面、分类、备注简介和阅读配置按选项迁移。
- [ ] 旧章节标题映射到新目录合理位置，不直接跳到章首或错误章节。
- [ ] 换源后退出、杀进程并重进，仍使用新书源和正确进度。
