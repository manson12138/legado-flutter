# M8 仿真翻页模式实施分析

> 文档状态：`IN_PROGRESS / 仿真翻页代码已写入，等待用户 Android、iOS 真机验证`
>
> 创建日期：2026-07-27
>
> 目标平台：Android、iOS 共用 Flutter 实现
>
> Android 只读基准：`legado-with-MD3/app/src/main/java/io/legado/app/ui/book/read/page/`

## 1. 结论

当前 Flutter 阅读器已经具备稳定字符锚点、真实文本分页、长章节增量分页、最近三套分页 LRU、
左右覆盖翻页、跨章节覆盖衔接、原生文字选区和全局阅读配置。仿真翻页应作为现有
`ReaderPageTurnStyle` 的第四种动画策略接入，不新建阅读状态机，不改变正文、章节、进度或数据库模型。

推荐使用纯 Flutter 实现：

- `Path` 和二次贝塞尔曲线计算卷页边界；
- `ClipPath` 分离当前页正面、目标页和翻起页背面；
- `Transform` 对页背执行沿折线的反射；
- `CustomPainter` 绘制折痕、正面阴影、背面阴影和轻量纸张背面着色；
- `AnimationController` 处理点击翻页、音量键翻页、拖动提交和取消回弹；
- `RepaintBoundary` 隔离参与动画的页面，避免每帧重新排版正文；
- 继续使用现有 `ReaderTextPage`、分页缓存和稳定字符锚点。

该方案不需要新增依赖，也不需要 Kotlin/Swift 平台桥接。Android 与 iOS 使用同一套 Dart/Flutter
几何、手势和动画代码。

## 2. 唯一目标与不包含范围

本专项唯一目标：

> 在小说文本阅读器的左右分页模式中新增可持久化的“仿真”翻页动画，支持拖动跟手、点击/音量键
> 自动翻页、取消回弹、上一页/下一页和相邻章节衔接，并保持文字选区、阅读进度和长章节分页稳定。

本专项不包含：

- Android 菜单中的“模拟追读（Simulated Reading）”；它与卷页动画不是同一功能；
- 淡入翻页、自动翻页、宽屏双页、漫画/PDF 仿真翻页；
- 背景图、纸张纹理或新主题系统；
- 修改 Android 参考工程；
- 新增第三方翻页库；
- 修改数据库 Schema、应用版本号、路由参数或平台通道；
- 顺带重构正文获取、替换规则、下载、TTS 或书签业务。

## 3. 当前 Flutter 基线

### 3.1 已可复用能力

| 能力 | 当前实现 | 本专项复用方式 |
|---|---|---|
| 分页模型 | `ReaderTextPage`、`ReaderPageLine` | 仿真只改变页面呈现，不重新切正文 |
| 分页测量 | `ReaderPageLayoutEngine` | 继续使用真实字体、标题、段落、页眉页脚测量结果 |
| 长章节首屏 | 首批 8 页 + 后台分批续算 | 仿真只允许翻到已生成页面，完整分页未完成时保持现有等待语义 |
| 分页缓存 | `ReaderPageLayoutCache` 最近三套 LRU | 不新增第二套页缓存 |
| 覆盖动画 | `_ReaderPagedContentState` 的跟手拖动和提交阈值 | 复用页面索引、方向、点击、按键和进度提交逻辑 |
| 跨章节衔接 | `_ReaderChapterCoverSwitch` | 泛化为按动画策略选择覆盖或仿真衔接 |
| 文字选区 | `ReaderSelectionRegion`、`ReaderTapRegion` | 选区激活时禁止卷页手势，翻页成功后清除旧选区 |
| 配置持久化 | `ReaderDisplayConfig` + `ReaderRepository` 全局缓存 JSON | 新增枚举名 `simulation`，旧配置无需迁移 |
| 稳定进度 | 章节 URL、章节索引、字符位置和摘要 | 仿真完成后仍只提交目标页 `startOffset` |

### 3.2 当前缺口

`ReaderPageTurnStyle` 目前只有：

- `cover`
- `none`
- `slide`

左右覆盖模式使用整页水平位移，不包含：

- 从触点所在页角产生的卷曲折线；
- 当前页未翻起区域的曲线裁剪；
- 页背反射内容；
- 折痕和前后页阴影；
- 仿真模式的跨章节呈现。

| Android 参考 | 关键行为 | Flutter 对应 |
|---|---|---|

| `sheet/PageAnimConfigSheet.kt` | 翻页动画下拉项显示“仿真” | `reader_settings_sheet.dart` 的动画选项 |
| `page/ReadView.kt#upPageAnim` | 根据配置创建 `SimulationPageDelegate` | `ReaderPagedContent` 根据 `pageTurnStyle` 选择呈现器 |
| `page/delegate/PageDelegate.kt` | 动画生命周期、按键翻页、完成/取消 | 现有分页 State 的动画控制器和页面提交逻辑 |
| `page/delegate/HorizontalPageDelegate.kt` | 触摸松弛阈值、方向、前后页准备 | 现有水平拖动状态 + 选区冲突保护 |
| `page/delegate/SimulationPageDelegate.kt` | 页角、贝塞尔曲线、页背矩阵、四组阴影 | 新增 `reader_simulation_page_turn.dart` |
| `page/provider/TextChapterLayout.kt` | 仿真模式继续使用普通分页结果 | 继续使用 `ReaderPageLayoutEngine`，不复制分页 |

需要保持的 Android 用户可观察行为：

1. 左滑翻下一页，右滑翻上一页。
2. 页面从手指触点附近的上角或下角卷起。
3. 翻起区域可看到当前纸张背面，底层显示目标页。
4. 折痕两侧具有方向一致的阴影，不是普通页面缩放或旋转。
5. 拖动未达到提交条件时回弹到当前页。
6. 拖动达到距离或速度条件时完成翻页。
7. 点击左右区域和音量键也使用仿真动画。
8. 动画进行中不重复启动第二次翻页。
9. 到达章节边界时沿相同方向进入相邻章节；无相邻章节时不改变进度。
10. 翻页完成才写入目标页稳定字符位置，取消不写入。

Flutter 不逐行移植 Android `Canvas`/`Bitmap` 代码，但保留相同几何概念、方向、层级和完成语义。

## 5. 推荐实现结构

### 5.1 新增独立呈现文件

新增：

`lib/src/ui/reader/reader_simulation_page_turn.dart`

职责限定为：

- 仿真卷页几何计算；
- 当前页、目标页和页背的裁剪/变换；
- 折痕和阴影绘制；
- 仿真帧 Widget；
- 跨章节程序化仿真帧可复用入口。

该文件不负责：

- 加载正文；
- 改变章节；
- 保存进度；
- 读取配置；
- 查询数据库；
- 控制系统栏。

### 5.2 几何模型

几何输入：

- 页面 `Size`；
- 翻页方向：上一页或下一页；
- 手势起点；
- 当前触点；
- 选定页角；
- 动画进度。

几何输出：

- 当前页仍可见区域；
- 翻起页背区域；
- 目标页已露出区域；
- 折痕线；
- 正面阴影和背面阴影路径；
- 页背反射矩阵；
- 阴影方向和强度。

计算沿用 Android `SimulationPageDelegate` 的核心关系：

1. 由触点和页角求中点；
2. 由中点求两条贝塞尔曲线控制点；
3. 求贝塞尔起点、终点和顶点；
4. 生成卷页闭合路径；
5. 以折线为轴反射当前页形成页背；
6. 按触点到页角距离缩放阴影范围。

所有除法使用最小 epsilon，所有点在绘制前检查 `isFinite` 并收窄到受控扩展视口。极端触点、
零尺寸和旋转中间帧不得产生 `NaN`、无限坐标或无界 Path。

上一页使用水平镜像后的同一套规范化几何，避免维护两份容易产生方向差异的公式。

### 5.3 页面渲染层级

仿真动画期间固定使用以下层级：

```text
目标页（完整底层）
  -> 当前页正面（裁剪掉已卷起区域）
  -> 当前页背面（沿折线反射，只绘制卷起区域）
  -> 页背轻量着色
  -> 折痕与前后阴影
```

不把页面转成长期持有的 `ui.Image`：

- 避免三张全屏高 DPR 位图长期占用内存；
- 避免异步截图造成第一次拖动无响应；
- 避免配置变化、图片加载和标注变化后截图失效；
- 不引入需要手动 `dispose` 的位图生命周期。

页面内容仍由现有 `_buildPage` 构建。动画期间只构建当前页正面、当前页背面和目标页三个有界层，
并用 `RepaintBoundary` 隔离；空闲状态恢复为单页。页背副本禁用选择、语义和点击，防止重复菜单与
辅助功能节点。

### 5.4 动画和手势状态

`_ReaderPagedContentState` 继续持有唯一页面动画控制器，避免覆盖和仿真各自创建互相竞争的控制器。

需要把当前 `_coverController` 和覆盖专用字段泛化为页面切换状态：

- 起始页索引；
- 目标页索引；
- 方向；
- 手势起点；
- 当前触点；
- 页角；
- 当前是否拖动；
- 当前是提交动画还是取消动画。

手势规则：

- 只有 `horizontalPaging + simulation` 进入仿真拖动；
- 移动超过 Flutter `kTouchSlop` 后才取得翻页控制；
- 左滑目标为下一页，右滑目标为上一页；
- 距离达到页面宽度 `22%` 或水平速度达到 `500 logical px/s` 时提交，保持当前覆盖模式手感基线；
- 未达到阈值时按剩余距离回弹；
- 点击翻页默认从对应下角开始；
- 音量键翻页使用同一程序化入口；
- 动画期间忽略新的翻页请求；
- Widget 销毁、切章、切换模式或尺寸变化时立即停止动画并清理本地状态。

### 5.5 文字选择冲突

现有 `ReaderTapRegion` 已避免短按加入 Flutter 手势竞技场，但覆盖/仿真拖动仍由外层
`GestureDetector` 识别。为避免拖动选择手柄时卷页，需要补充：

1. `ReaderTapRegion` 向分页 State 上报当前是否存在有效选区；
2. 选区激活期间不启动水平翻页；
3. 长按未发生水平移动时继续由 `SelectionArea` 获胜；
4. 翻页提交后递增 `selectionEpoch` 清理旧选区；
5. 取消回弹不改变选区和字符锚点；
6. 动画层使用 `IgnorePointer` 与 `ExcludeSemantics`。

这部分是仿真模式可用性的必要条件，不是额外业务重构。

### 5.6 长章节后台分页竞争

后台完整分页可能在用户卷页期间完成。不能在卷页中途替换 `_pages`，否则路径对应的页面会突变。

处理规则：

- 拖动或动画期间完成的完整页集先保存为本地待应用结果；
- 翻页提交或回弹结束后，以当前稳定字符位置重新定位并一次性应用；
- 切章、配置变化或布局代次变化时丢弃旧待应用结果；
- LRU 仍只保存最近三套完整分页，不新增动画页缓存；
- 首批分页尚未生成目标页时不启动仿真，继续显示现有轻量分页中状态。

## 6. 配置与兼容策略

### 6.1 配置模型

在 `ReaderPageTurnStyle` 增加：

```text
simulation
```

`ReaderRepository` 当前按枚举 `name` 保存和兼容读取，因此：

- 新配置写入 `"pageTurnStyle":"simulation"`；
- 旧配置继续按原值读取；
- 未知或损坏值继续回退 `cover`；
- 不需要新增缓存键；
- 不需要数据库 Schema 升级；
- 不需要调整 `pubspec.yaml` build number。

### 6.2 设置交互

“显示设置 → 样式 → 翻页动画”新增“仿真”。

Flutter 将阅读方式和动画策略分开保存，规则如下：

- 用户选择“仿真”时自动切换为“左右翻页”，保证选择后立即看到效果；
- 用户之后切到连续滚动或上下翻页时，保留 `simulation` 配置但不执行卷页；
- 再切回左右翻页时恢复仿真；
- 不把上下翻页的普通垂直 PageView 冒充仿真。

## 7. 跨章节行为

当前章内最后一页继续下一页或第一页继续上一页时：

1. 先提交 `OpenNextChapterIntent` 或 `OpenPreviousChapterIntent`；
2. 加载期间继续保留旧页和顶部线性进度，不显示整页空白；
3. 新章节完成分页后，按保存的章节切换方向执行一次程序化仿真动画；
4. 下一章显示第一页，上一章显示末页；
5. 动画完成后只保存目标章节对应的稳定字符锚点；
6. 加载失败时保留旧页并显示现有错误，不播放假完成动画。

为此将 `_ReaderChapterCoverSwitch` 泛化为按 `ReaderPageTurnStyle` 分派的章节切换容器。覆盖模式行为必须
保持不变，仿真模式复用新增卷页帧，无动画和滑动继续走现有路径。

## 9. 性能和内存约束

1. 不新增全屏位图缓存，不长期持有 `ui.Image`。
2. 空闲状态只构建当前页；动画状态最多构建当前正面、当前背面和一个目标页。
3. 正文分页结果仍使用三套 LRU，不因仿真模式扩大。
4. 几何对象只保存当前帧必要点和 Path，不保存历史轨迹。
5. 页面正文用 `RepaintBoundary` 隔离，动画帧不得重新执行分页和正文业务处理。
6. `AnimatedBuilder` 的静态页面作为 child 复用，帧更新只改变裁剪、矩阵和阴影。
7. 阴影使用有限范围线性渐变，不使用大半径模糊滤镜或全屏 `saveLayer`。
8. 配置/尺寸/章节改变时取消旧动画；后台分页使用现有代次校验，防止过期结果回填。
9. 动画控制器在 `dispose` 中释放，不创建 Timer、Stream 或平台监听器。
10. 页面背面副本不注册选区、点击和语义节点，减少手势与可访问性开销。

## 10. 风险与降级

| 风险 | 处理 |
|---|---|
| 极端触点导致贝塞尔除零或 Path 异常 | epsilon、有限值检查、坐标收窄；失败帧回退覆盖动画而不是崩溃 |
| 低端设备卷页掉帧 | 无截图、有限三层、RepaintBoundary、轻量线性阴影；由用户真机确认 |
| 图片页动画时重复构建 | 只构建当前和目标页，依赖 Flutter 图片缓存；动画结束立即释放额外层 |
| 选区手柄拖动触发翻页 | 上报选区激活状态并禁用外层水平拖动 |
| 后台分页完成导致卷页跳变 | 动画期间延迟应用完整页集 |
| 快速连续点击串页 | 动画运行时拒绝第二次请求，完成后才更新页索引和锚点 |
| 跨章加载失败却播放翻页 | 只有目标章节正文与分页就绪后才启动跨章动画 |
| iOS 与 Android 阴影观感略有差异 | 使用同一 Flutter Canvas/Path；记录真机差异，不拆两套实现 |

几何无法安全计算的单帧允许降级为现有覆盖呈现，但配置仍保持“仿真”，下一次正常手势继续尝试仿真。
降级不得改变页码、章节或阅读进度。

## 11. 用户验收清单

代码实施后由用户执行检查和真机验收，AI 不运行构建、分析、测试、格式化或应用启动。

### 11.1 基础配置

1. 打开“显示设置 → 样式”，确认翻页动画包含“仿真”。
2. 在连续滚动状态选择“仿真”，确认自动切到左右翻页。
3. 退出阅读器并打开其他书，确认全局仿真设置恢复。
4. 切到上下翻页或连续滚动，确认不会错误显示横向卷页；再切回左右翻页后恢复仿真。

### 11.2 手势与动画

1. 从右下角、右上角和页面中部向左拖动，确认卷页折线跟随触点且没有闪烁、黑块或内容倒置。
2. 向右拖动返回上一页，确认方向、目标页和页背正确。
3. 小距离拖动后松手，确认平滑回弹且页码、进度不变。
4. 大距离或快速甩动，确认完成翻页且只前进/后退一页。
5. 连续快速点击左右区域，确认动画期间不会重复翻两页或页面错乱。

### 11.3 章节、分页和恢复

1. 从章末卷入下一章，再从下一章首页卷回上一章，确认旧页在加载期间保留，完成后方向正确。
2. 打开超长章节，在后台总页数从省略号收敛期间翻页，确认不跳页、不回章首。
3. 修改字号、行高、边距、标题样式和方向后，确认动画取消并按稳定字符位置重新分页。
4. 翻页后立即返回、切后台或杀进程重进，确认恢复到已完成翻页的目标页附近。
5. 取消回弹后退出重进，确认仍在原页附近。

### 11.4 选区、图片和稳定性

1. 长按正文并拖动选择手柄，确认不会触发卷页。
2. 有选区时点击正文先交给选择系统处理，不误翻页；完成翻页后旧选区消失。
3. 在高亮、下划线和正文图片页上翻页，确认内容层级、页背和阴影正常。
4. Android 与 iOS 真机分别连续翻页至少 5 分钟，观察帧率、发热和内存是否持续增长。
5. 旋转、分屏、前后台切换后继续翻页，确认没有残留动画、异常 Path 或无响应手势。
